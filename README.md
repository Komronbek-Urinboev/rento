# Монополия Мир — Онлайн

**Полная реализация игры Монополия (Мировое издание) для игры через браузер.**

## Возможности

- **Мультиплеер в реальном времени** — играйте с друзьями по всему миру через уникальный код комнаты
- **Режимы игры** — каждый сам за себя или командный режим (2–3 команды)
- **Полные правила Монополии** — покупка, аренда, строительство домов/отелей, залог, аукционы, тюрьма, карты шанса/казны
- **До 6 игроков** в одной комнате
- **Красивый интерфейс** — тёмная деревянная тема, 3D фишки, анимация кубиков

## Как играть

### Создать игру (хост)
1. Откройте сайт
2. Введите своё имя и выберите цвет фишки
3. Настройте параметры игры (число игроков, деньги, команды)
4. Нажмите **«Создать игру»**
5. Поделитесь **кодом комнаты** (длинная строка) с друзьями

### Присоединиться
1. Откройте сайт
2. Перейдите на вкладку **«Присоединиться»**
3. Введите имя, выберите цвет, вставьте **код комнаты**
4. Нажмите **«Подключиться»**

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы в репозиторий
3. Зайдите в **Settings → Pages**
4. Выберите источник: `main` ветка, папка `/` (root)
5. Сохраните — сайт будет доступен по адресу `https://ваш-логин.github.io/имя-репозитория/`

```bash
git init
git add .
git commit -m "Монополия Мир — первый релиз"
git remote add origin https://github.com/ВАШ_ЛОГИН/monopoly-world.git
git push -u origin main
```

## Структура проекта

```
├── index.html          # Лобби (создать/присоединиться)
├── game.html           # Игровое поле
├── css/
│   └── style.css       # Все стили
└── js/
    ├── config.js       # Данные доски, карты шанса/казны
    ├── network.js      # PeerJS сетевой слой (P2P)
    ├── engine.js       # Игровой движок (правила)
    └── game.js         # Контроллер клиента (рендер + UI)
```

## Технологии

- **PeerJS** (WebRTC) — P2P мультиплеер без сервера
- Чистый HTML/CSS/JS — без фреймворков
- CSS Grid — для рендера доски
- GitHub Pages — хостинг
